# Ice Printing 3D
Dolfinx based 3D printing library for phase field solidification of additive constructed domains

## Uses
- Simulate the temperature and phase change of a 3D printed domain.

## Installation
Find details of installation at [Dolfinx's Github](https://github.com/FEniCS/dolfinx#installation). This model was implemented with Dolfinx v0.9.0.
